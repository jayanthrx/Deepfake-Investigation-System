🔍 About Deepfake Investigation System

Project Overview

The Deepfake Investigation System is an AI-based digital forensic application designed to detect manipulated images and videos. The system uses deep learning techniques to classify media as Real or Fake and provides explainable results.

Technology Used

  • EfficientNet Deep Learning Model
  • TensorFlow / Keras
  • OpenCV Video Analysis
  • Flask Web Framework
  • SQLite Investigation Database
  • Grad-CAM Explainable AI

Implemented Features

  • ✔ Image Deepfake Detection
  • ✔ Video Frame Analysis
  • ✔ Fake / Real Probability Prediction
  • ✔ Confidence Score Calculation
  • ✔ Risk Level Assessment
  • ✔ AI Heatmap Visualization
  • ✔ PDF Investigation Report Generation
  • ✔ Investigation History Dashboard

Model Performance

Overall Accuracy: 69.86%
