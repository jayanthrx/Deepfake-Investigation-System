🏗 Deepfake Investigation System Architecture

System Workflow

User uploads image/video → Media preprocessing → EfficientNet Deep Learning Model → Prediction → Confidence Calculation → Risk Assessment → Grad-CAM Explanation → PDF Report Generation → Database Storage

Architecture Diagram

Major Components

1. User Interface
Flask Web Application for uploading and viewing results.

2. Deep Learning Model
EfficientNet model classifies media as Real or Fake.

3. Video Detector
Extracts frames and analyzes video content.

4. Explainable AI
Grad-CAM generates heatmaps showing suspicious regions.

5. Report Generator
Creates PDF investigation reports.

6. Database
Stores previous investigation history.
